# Smart Event Dashboard 

## 📌 Project Description
The Smart Event Dashboard is a web-based application that allows users to add, manage, and delete events dynamically using JavaScript and DOM manipulation.

---

## 🚀 Features
- Add new events using a form
- Display events dynamically
- Delete individual events
- Clear all events
- Add sample events
- Display pressed keyboard key (DOM Manipulation Demo)

---

## 🛠 Technologies Used
- HTML5
- CSS3 (Grid Layout)
- JavaScript (DOM & Event Handling)

---

## 📚 Concepts Used
- DOM Manipulation
- Event Listeners
- Event Delegation
- Form Handling
- Dynamic Element Creation
- CSS Grid Layout

---

## 🎓 Purpose
This project was created as part of a Web Development lab assignment to demonstrate understanding of DOM manipulation and event handling in JavaScript.
